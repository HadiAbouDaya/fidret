# Candidate Lab pieces

These are unassigned ideas for discussion, not claims of completed work. Choose a topic that matches the author's interests and current skills. Each can begin conceptually and become more concrete in later pieces.

| Question | Possible format | A useful first piece |
| --- | --- | --- |
| How does camera placement affect a visual inspection system? | Architecture note, followed by a simulation | Explain the tradeoffs and assumptions with a labelled diagram |
| What should a connected system do when sensor readings stop arriving? | Technical note or local prototype | Walk through timeout, stale-data, and recovery behavior |
| How would we evaluate a robot task before touching hardware? | Architecture note or simulation | Define a bounded task and explain the proposed evaluation approach |
| When should an automated system ask a human for help? | Technical note or prototype | Explore a small decision flow, including uncertain inputs and a useful fallback |

Keep the first scope modest. Neither a physical robot nor a client deployment is required. Record what was actually explored and what remains proposed.

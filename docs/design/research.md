# Design skill research and adaptation

Reviewed 28 October 2026 for the [design revamp](../tasks/2026-10-28-design-revamp.md). “Least AI slop” has no objective universal ranking. The selection below is a judgment about fit with Fidret's purpose and this requested redesign.

## Selected foundation

[Paul Bakaus's Impeccable](https://github.com/pbakaus/impeccable), inspected at [commit 7510e233b228864606888d252abacf5e7148bf87](https://github.com/pbakaus/impeccable/tree/7510e233b228864606888d252abacf5e7148bf87), skill version 4.8.0, is the strongest fit of the reviewed candidates. Its useful contribution is to connect design ambition to a surface's task, challenge generic generated patterns and require looking at rendered work. Those ideas inform the small, original [Fidret skill](../../skills/fidret-design/SKILL.md).

The installed [Anthropic frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) contributes a compact creative discipline: derive the visual idea from the subject and review the result as a coherent composition. [Vercel's web-design-guidelines skill](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md) serves a different purpose: reviewing interface implementation. It is a useful review reference rather than the basis for Fidret's identity.

## Deliberate adaptation

The repository retains its existing charter, source map and task workflow instead of creating a parallel product-context system. It keeps one canonical design brief and one small skill that routes to it. The adaptation does not install upstream executables, auto-download launchers, hooks, randomized concept tournaments or mandatory approval rounds. Hadi has already delegated the redesign choices; additional workflow machinery would not improve this task.

No Impeccable executable or deterministic detector was run as part of this selection. The adaptation is original project-specific prose, not a vendored copy of upstream playbooks or code. The inspected Impeccable and Anthropic skills are Apache-2.0 licensed; future copying or redistribution must preserve the applicable license and notices. Font assets retain their separate [OFL provenance](font-sources.md).

## Reference principles

These primary-source references inform judgment. No reference imagery, logos, renders, project claims or source code are included in the website by this research.

| Reference | Principle studied | Application to Fidret |
| --- | --- | --- |
| [Pentagram: Stereolabs](https://www.pentagram.com/work/stereolabs) | A consistent visual system can explain a spatial-computing subject | Develop an original sensing/observation grammar, without borrowing its symbol or commercial proof |
| [Pentagram: Intrinsic](https://www.pentagram.com/work/intrinsic) | Expressive form can arise from the actual robotics subject | Make the signature artifact about observation and evidence rather than arbitrary animation |
| [Pentagram: Vertical](https://www.pentagram.com/work/vertical) | Ambitious identity and engineering detail can support each other | Use precise graphics without implying Fidret owns an equivalent physical product |
| [Vitsœ: good design](https://www.vitsoe.com/gb/about/good-design) | Usefulness, understandability, honesty and durability | Favor an inspectable experiment and readable limits over fabricated portfolio material |

The selected direction, **A working field of evidence**, makes the existing synthetic signal-freshness exploration the useful interactive artifact. Forest, ivory, sage, copper and the licensed Manrope/Newsreader assets maintain continuity, while composition, scale and original figures make the redesign substantial. A gallery of supposed client work was rejected because the current evidence cannot support it.

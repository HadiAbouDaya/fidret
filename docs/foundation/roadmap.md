# Fidret foundation roadmap

Advance when there is enough evidence for the next commitment. Timing and ownership for future stages should be agreed when each task is opened.

| Stage | Output | Condition for progressing |
| --- | --- | --- |
| Establish the shared foundation | Company charter, agent context, contribution workflow, checks, and task records | Hadi and Elie can each use their harness to continue a task and review the result |
| Select a first physical AI problem | Discovery notes and a short list of opportunities | A specific user, accessible environment, meaningful outcome, and feasible evaluation are identified |
| Demonstrate a narrow capability | Reproducible experiment with baseline, results, and limits | Evidence supports a useful result under stated conditions and explains important failures |
| Define the first offer | Scope, deliverables, dependencies, acceptance criteria, and responsibilities | The work can be delivered credibly with a clear client commitment |
| Run a bounded pilot | Agreed trial and documented evaluation | The client and delivery owner can assess the result against the agreed criteria |
